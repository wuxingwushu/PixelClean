## 1. 全部 `CollideAABB(...)` 重载

共 7 个。全部是"中心距 vs 半径和"的**圆形包围体近似**，不是真正的轴向包围盒（没有用 `min/max` 端点，也没有 `Shape` 的半宽半高，只用了标量 `radius`）。全部只做 X、Y 两轴判断 → 3D 必须补 Z 轴。

|---|---|---|---|
| 1 | `bool CollideAABB(PhysicsShape* ShapeA, PhysicsShape* ShapeB)` | .cpp:16-28 | `FLOAT_ R = ShapeA->radius + ShapeB->radius;`（:18）；`abs(ShapeA->pos.x - ShapeB->pos.x) > R` → false（:19-22）；同式 Y（:23-26）；否则 true |
| 2 | `bool CollideAABB(PhysicsShape* Shape, PhysicsCircle* Circle)` | .cpp:37-49 | `R = Shape->radius + Circle->radius`（:39）；X 分量（:40-43）、Y 分量（:44-47） |
| 3 | `bool CollideAABB(PhysicsShape* Shape, PhysicsParticle* Particle)` | .cpp:59-70 | 点无半径，只与 `Shape->radius` 比：X（:61-64）、Y（:65-68） |

**3D 影响**：7 个重载全部要加第三轴；`PhysicsLine` 的 `angle` 是**单个标量**（2D 姿态），3D 下线需要 `(theta, phi)` 或方向向量 + `length`，`vec2angle` 旋转需换成方向向量构造 AABB（`abs(dir.x)*halfLen` 形式推广到 3 轴）。

## 2. 全部 `Collide(Contact* contacts, ...)` 重载

公共前置事实：
- 输出写入调用方提供的 `Contact contacts[PhysicsContactMaxSize]`（=20，`BaseArbiter.hpp:198`）。
- `w_side` 在 `Collide` 内被写成**当前接触点序号**（`contacts->w_side = ContactSize;`），但在 `PhysicsArbiter.cpp` 的 `ComputeCollide()` 里紧接着被**整体覆盖为 `i`**（如 :10-12）。两者数值相同，语义是"槽位 id"，用于下一帧 `Update` 的冲量热启动。
- 分离深度统一约定：**负值表示穿透**，写法恒为 `contacts->separation = -abs(...)` 或 `L - radius`。
- 摩擦统一取两者**几何平均**：`SQRT_(fA * fB)`。
- 法线统一由 `vec2angle({-1, 0}, angle)` 构造。由 `BaseCalculate.hpp:142-145` 展开：`vec2angle((-1,0), θ) = (-cosθ, -sinθ)`，即**角度方向的负向单位向量**。

### 2.1 Shape × Shape（SS）— `Collide(Contact*, PhysicsShape*, PhysicsShape*)`，.cpp:166-233

- 算法：**双向轮廓点 Bresenham 射线检测**，不是 SAT、不是 GJK。两轮各自从"旧位置→当前位置"的位移轨迹做体素步进，命中面即碰撞面。
- 第一轮（:174-201）：遍历 `ShapeA->OutlineSet`，`Drop = Mat.Rotary(Drop)`（:177，`AngleMat Mat(ShapeA->angle)` :168），`DropPos = ShapeA->pos + Drop`（:178），调用 `ShapeB->PsBresenhamDetection(ShapeA->OldPos + Mat.Rotary(ShapeA->MaxOutlineCentreMass[i]), DropPos)`（:179）。
- 第二轮（:206-231）：`Mat.SetAngle(ShapeB->angle)`（:205）后对称，法线取反。
- 接触点数上限：`OutlineSize_A + OutlineSize_B`，**被 `ContactSize < PhysicsContactMaxSize` 截断**（:174、:206）——这是全文件**仅有的两处越界保护**。
- 法线：`contacts->normal = vec2angle({-1, 0}, (info.Direction * (M_PI / 2)) + ShapeB->angle);`（:196）；第二轮 `contacts->normal = -vec2angle({-1, 0}, (info.Direction * (M_PI / 2)) + ShapeA->angle);`（:226）。
- 分离：由 `info.Direction & 0x1` 二选一轴（:183-190 / :214-221）：X 轴时 `info.pos.y - DropPos.y`，否则 `info.pos.x - DropPos.x`，随后 `-abs`（:191/:222）。
- 摩擦：`SQRT_(info.Friction * ShapeA->FrictionSet[i])`（:193）/ `SQRT_(info.Friction * ShapeB->FrictionSet[i])`（:223）。
- 2D 构造：`Vec2_`、`AngleMat::Rotary`（标量角旋转矩阵）、`vec2angle({-1,0}, θ)`、`info.Direction*90°`（**把 0/1 轴向编码乘 90° 得到 0 或 π/2**）、`Direction & 0x1` 二轴判别、Bresenham 体素行进。

### 2.2 Shape × Particle（S-Particle）— .cpp:245-276

- 算法：**两段式**。先包含性测试 `Shape->DropCollision(Particle->pos).Collision`（:248），再 Bresenham 位移射线 `Shape->PsBresenhamDetection(Particle->OldPos, Particle->pos)`（:252）。
- 接触点数：**最大 1**（`return 1` :272）。
- 法线：`contacts->normal = -vec2angle({-1, 0}, (info.Direction * (M_PI / 2)) + Shape->angle);`（:267）。
- 分离：`info.Direction & 0x1` 选轴（:256-263）+ `-abs`（:264）。
- 摩擦：`SQRT_(info.Friction * Particle->friction)`（:265）。
- **副作用**：`Particle->OldPos = info.pos + (contacts->normal * FLOAT_(0.1));`（:270）把粒子旧位置沿法线推出 0.1，并置 `Particle->OldPosUpDataBool = false;`（:271）——这是 2D 位置的"防卡"修正，3D 需要 `Vec3_` 版本。

### 2.3 Shape × Map（S-Map）— .cpp:288-368

- 算法：**双向 Bresenham**。第一轮形状轮廓点 → 地形 `Map->FMBresenhamDetection(...)`（:303）；第二轮取地形轻量轮廓 `Map->FMGetMinOutline(...)`（:330-335）后反向检测 `Shape->PsBresenhamDetection(Drop - (Shape->pos - Drop), Drop)`（:345）。
- 包围盒查询范围（**2D 整数网格窗口**）：`ToInt(Shape->pos.x - Shape->radius) - KD, ToInt(Shape->pos.y - Shape->radius) - KD, ToInt(Shape->pos.x + Shape->radius) + KD, ToInt(Shape->pos.y + Shape->radius) + KD`，`int KD = 1;`（:327）。
- 快速剔除：`if (!Shape->DropCollision(Drop).Collision) continue;`（:340）。
- 接触点数：`Shape->OutlineSize + Outline.size()`，**无上限保护** → 超过 20 会写穿 `contacts[]`。
- 法线：第一轮 `vec2angle({-1, 0}, info.Direction * (M_PI / 2))`（:318，地形无旋转，**不叠加角度**）；第二轮 `-vec2angle({-1, 0}, info.Direction * (M_PI / 2) + Shape->angle)`（:360）。
- 摩擦：`SQRT_(info.Friction * Shape->FrictionSet[i])`（:315）/ `SQRT_(info.Friction * Outline[i].F)`（:357）。
- 2D 构造：`Vec2_ mapCentrality = Map->FMGetCentrality();`（:328）、`MapOutline`（含 `.pos`、`.F`、`.face`）、`ToInt` 二维取整、Bresenham、`Direction & 0x1`。

### 2.4 Particle × Map（Particle-Map）— .cpp:380-414

- 算法：先区域查询 `Map->FMGetCollide(Particle->pos)`（:388，注释 :385-387 明确指出必须走 `Vec2_` 重载以加 `centrality`，否则地图负坐标区失效），再 Bresenham `Map->FMBresenhamDetection(Particle->OldPos, Particle->pos)`（:391）。
- 接触点数：**最大 1**（:410）。
- 法线：`vec2angle({-1, 0}, info.Direction * (M_PI / 2))`（:405）。
- 分离：轴选择（:394-401）+ `-abs`（:402）。
- 摩擦：`SQRT_(info.Friction * Particle->friction)`（:403）。
- 副作用：`Particle->OldPos = info.pos - (contacts->normal * FLOAT_(0.1));`（:408）——注意与 §2.2 的 **符号相反**（+0.1 vs -0.1），3D 转换时需保留该行为差异或统一。

### 2.5 Circle × Map（Circle-Map）— .cpp:426-494

- 算法：**四方向采样点 Bresenham + 地形轮廓点距离测试**的混合。
- 第一轮（:432-461）：采样点 `Cd`（:434-438）为 `pos ± (radius,0)`、`pos ± (0,radius)`，即**世界轴上 +x/+y/−x/−y 四向**；对每点 `Map->FMBresenhamDetection(Circle->OldPos, d)`（:442）。上限 4。
- 第二轮（:463-492）：`int KD = 2;`（:465）窗口 `FMGetMinOutline(ToInt(pos.x - r) - KD, ToInt(pos.y - r) - KD, ToInt(pos.x + r) + KD, ToInt(pos.y + r) + KD, Outline)`（:468-473）；`d.pos -= mapCentrality;`（:478）；`d.pos = d.pos - Circle->pos;`（:479）；`L = ModulusLength(d.pos);`（:480，距离平方）；`if ((Circle->radius * Circle->radius) > L)`（:481）；`L = SQRT_(L);`（:483）；`contacts->separation = L - Circle->radius;`（:484）；`contacts->normal = d.pos / L;`（:486，圆心指向轮廓点）；`contacts->position = contacts->normal * Circle->radius + Circle->pos;`（:487）。
- 接触点数：`4 + Outline.size()`，**无上限保护**。
- 摩擦：`SQRT_(info.Friction * Circle->friction)`（:454）/ `SQRT_(d.F * Circle->friction)`（:485）。
- 2D 构造：四点固定轴采样（**不是球面均匀采样**）、二维 `MapOutline`、`ModulusLength` 平方距离比较、`Direction & 0x1`。

### 2.6 Circle × Particle（Circle-Particle）— .cpp:505-521

- 算法：**纯距离测试**，无 Bresenham。`Vec2_ dp = Particle->pos - Circle->pos;`（:507）；`FLOAT_ L = ModulusLength(dp);`（:508，实为距离平方）；`FLOAT_ R2 = Circle->radius * Circle->radius;`（:509）；`if (R2 > L)`（:510）。
- 接触点数：**最大 1**。
- 命中后：`L = SQRT_(L);`（:512）；`contacts->separation = L - Circle->radius;`（:513）；`contacts->normal = dp / L;`（:515）；`contacts->position = contacts->normal * Circle->radius + Circle->pos;`（:516）。
- 摩擦：`SQRT_(Particle->friction * Circle->friction)`（:514）。
- 2D 构造：`Vec2_` 减法、二维点积式平方距离、二维标量除法归一化。

### 2.7 Circle × Circle（CC）— .cpp:532-549

- 算法：圆心距平方比较。`Vec2_ dp = CircleB->pos - CircleA->pos;`（:534）；`L = ModulusLength(dp);`（:535）；`R = CircleA->radius + CircleB->radius;`（:536）；`R2 = R*R`（:537）；`if (R2 > L)`（:538）。
- 接触点数：**最大 1**。
- 命中后：`L = SQRT_(L);`（:540）；`separation = L - R;`（:541）；`normal = dp / L;`（:543，A→B）；`position = normal * CircleA->radius + CircleA->pos;`（:544）。
- 摩擦：`SQRT_(CircleB->friction * CircleA->friction)`（:542）。
- 2D 构造：同上，纯 `Vec2_`。3D 只需把 `ModulusLength` 换成 `x²+y²+z²`、`normal` 换 `Vec3_`，**算法零改动**（这是最容易迁移的一支）。

### 2.8 Circle × Shape（Circle-Shape）— .cpp:561-623

- 算法：**按形状姿态旋转的四方向采样 Bresenham + 形状轮廓点距离测试**。
- 第一轮（:566-598）：`AngleMat Mat(Shape->angle);`（:564）；`Vec2_ Rx = Mat.Rotary({Circle->radius, 0});`（:568）、`Vec2_ Ry = Mat.Rotary({0, Circle->radius});`（:569）；`Cd` 为 `pos ± Rx`、`pos ± Ry`（:571-575）；逐点 `Shape->PsBresenhamDetection(Circle->OldPos, d)`（:579）。上限 4。
- 第二轮（:600-620）：`dp = Shape->pos + Mat.Rotary(Shape->OutlineSet[i]) - Circle->pos;`（:607）；`L = ModulusLength(dp);`（:608）；`if (R2 > L)`（:609）；命中后 `separation = L - Circle->radius`（:612）、`normal = dp / L`（:614）、`position = normal * Circle->radius + Circle->pos`（:615）。
- 接触点数：`4 + Shape->OutlineSize`，**无上限保护**。
- 法线（第一轮）：`vec2angle({-1, 0}, info.Direction * (M_PI / 2) + Shape->angle)`（:593，**不加负号**，与 §2.1 第一轮同向；而 §2.2 的 S-Particle 带负号——同一物理方向在不同分支约定不一致，转换时需逐支核对）。
- 摩擦：`SQRT_(Circle->friction * info.Friction)`（:591）/ `SQRT_(Circle->friction * Shape->FrictionSet[i])`（:613）。
- 2D 构造：**用形状标量角构造 4 个共面采样方向**（`Rotary` 作用在 `(r,0)`/`(0,r)` 上），3D 必须换成球面多点采样（如 6 轴对齐 ±x/±y/±z，或 26 邻域方向）或直接做"球心到三角形最近点"。

### 2.9 Line × Shape（LS）— .cpp:734-829

- 算法：**四阶段**，混合"线段相交"与"Bresenham"：
  1. 形状轮廓边 × 线段相交（:753-767）：`segmentIntersection(begin, end, Shape->OldPos, DropPos, contacts->position)`（:758）。
  2. 线中心 Bresenham（:770-778）：`info = Shape->PsBresenhamDetection(Line->OldPos, Line->pos);`（:771）——**该阶段只设 `normal` 并推 OldPos，不产生接触点**（:774-777）。
  3. 起点 Bresenham（:781-802）：前置 `Shape->GetCollision(begin)`（:781），再 `PsBresenhamDetection(Line->OldPos, begin)`（:783）。
  4. 终点 Bresenham（:805-826）：`Shape->GetCollision(end)`（:805）+ `PsBresenhamDetection(Line->OldPos, end)`（:807）。
- 端点计算：`Vec2_ pR = vec2angle({Line->radius, 0}, Line->angle); Vec2_ begin = Line->pos + pR, end = Line->pos - pR;`（:737-738）。
- 法线（阶段 1）：预计算垂线 —— `Vec2_ AB = {end.x - begin.x, end.y - begin.y};`（:741）、`AP = {Shape->OldPos.x - begin.x, Shape->OldPos.y - begin.y}`（:742）、`t = Dot(AP, AB) / len`（:745，**注意 `len = ModulusLength(AB)` 是长度平方，故 `t` 不是标准投影参数——量纲错误**）、`normal = Shape->OldPos - (begin + (AB * t))`（:746）、`normal = normal / Modulus(normal)`（:747）。
- 法线（阶段 3/4）：`vec2angle({-1, 0}, info.Direction * (M_PI / 2))`（:797、:821）。
- 分离（阶段 1）：`contacts->separation = -Modulus(contacts->position - DropPos);`（:761，用交点与轮廓点的距离，**不是沿法线的投影**）；阶段 3/4 用 `Direction & 0x1` 选轴 + `-abs`（:786-794、:810-818）。
- 接触点数：`Shape->OutlineSize + (0..2)`，**无上限保护**。
- 2D 构造：`Dot`（二维点积）、`Modulus`/`ModulusLength`、`segmentIntersection`（依赖 §5 的 2D 叉积）、`vec2angle` 标量角、`Direction & 0x1`。

### 2.11 Line × Particle（LP）— .cpp:872-900

### 2.12 Line × Map（LM）— .cpp:913-1021

- 算法：**四阶段**，与 §2.9 同构但对象换成地形：

  3. 起点（:973-994）：`Map->FMGetCollide(begin)`（:973）+ `Map->FMBresenhamDetection(Line->OldPos, begin)`（:975）。
  4. 终点（:997-1018）：`Map->FMGetCollide(end)`（:997）+ `FMBresenhamDetection(Line->OldPos, end)`（:999）。
- 窗口：`int KD = 2;`（:928）+ `FMGetMinOutline(ToInt(pos.x - r) - KD, ToInt(pos.y - r) - KD, ToInt(pos.x + r) + KD, ToInt(pos.y + r) + KD, Outline)`（:931-936）。

## 5. 转 3D 必须修改的清单

### 5.1 数学基元层
1. **向量类型**：`Vec2_` → `Vec3_`；`Dot`、`Modulus`、`ModulusLength`、归一化全部升 3 分量（`ModulusLength` 需 `x²+y²+z²`）。
2. **标量角 → 3D 姿态**：`AngleMat`（单一 `angle` + `Rotary`，`PhysicsBaseCollide.cpp:168/205/564/751`）与 `vec2angle({-1,0}, θ)`（:196、:226、:267、:318、:360、:405、:456、:593、:774、:797、:821、:966、:989、:1013）在 3D 无意义。需要：四元数（或 3×3 旋转矩阵）表示姿态；`vec2angle({-1,0}, θ)` 的"法线 = −(cosθ, sinθ)"替换为显式 `Vec3_` 法线。
3. **叉积**：`Cross(const Vec2_&, const Vec2_&)`（标量）、`Cross(const Vec2_&, FLOAT_)`（垂线）、`Cross(FLOAT_, const Vec2_&)`（w×r）三种 2D 重载（`BaseCalculate.hpp:433/444/455`）必须替换为 3D 向量叉积；`Cross(c->r1, P)`（标量力矩）→ `Vec3_` 力矩向量；`Cross(object1->angleSpeed, c->r1)` → `ω × r`（`Vec3_`）。
4. **标量角速度/转动惯量**：`angleSpeed`（标量）、`invMomentInertia`（标量）→ `Vec3_` 角速度 + 3×3 逆惯量张量；角速度积分需用四元数微分并归一化。
5. **2D 线段相交**：`corssProduct`（:633-636）、`onSegment`（:646-654）、`segmentIntersection`（:666-721）整套 2D 专有，3D 需替换为线段-三角形最近点/相交或射线-三角形（Möller–Trumbore）；`DropUptoLineShortesIntersect`（:846）需换成"点→线段"的 3D 版本。

### 5.2 宽相（§1）
6. 7 个 `CollideAABB` 全部补 Z 轴判据（.cpp:16-154）；`PhysicsLine` 的旋转包围盒（:123、:144）改为 3D 方向向量在 3 轴上的投影。
7. 现有实现本身是"中心距 vs radius 和"的球体近似而非真 AABB，3D 若沿用可零成本推广（只是加一轴），但若要对齐体素网格的盒体需要改为 3 轴 min/max。

### 5.3 窄相（§2）
8. **SAT 缺失**：全文件**没有 SAT**。2D 只有 Bresenham 体素步进 + 距离测试 + 线段相交。3D 需要新增：盒-盒 **15 轴 SAT**（3+3+9）、球-盒最近点测试、凸体 SAT / GJK+EPA。
9. **Bresenham → 3D DDA**：`PsBresenhamDetection`（Shape）与 `FMBresenhamDetection`（Map）是**二维网格步进**，返回 `CollisionInfoD{ Collision, Direction, pos, Friction }`，其中 `Direction & 0x1` 编码 X/Y 两轴。3D 必须换成 Amanatides–Woo 3D DDA，`Direction` 扩为 3 位（X/Y/Z）或改用面法线枚举（6 个轴向）。所有 `info.Direction & 0x1` 的轴二选一分支（:183、:214、:256、:306、:348、:394、:445、:582、:786、:810、:978、:1002）改为三轴或 6 面法线表。
10. **`info.Direction * (M_PI / 2)`**（:196、:226、:318、:360、:405、:456、:593、:774、:797、:821、:966、:989、:1013）是"0/1 × 90°"的 2D 轴向编码 hack，3D 应直接查 6 个法线常量。
11. **Shape-Shape（§2.1）**：双向轮廓 Bresenham 需换成 3D 凸体 manifold（面裁剪）；法线取反的"第二轮"逻辑在 3D 需保证法线一致朝向（A→B）。
12. **Shape-Particle / Particle-Map（§2.2、§2.4）**：包含性测试 + 射线检测需 3D 化；`OldPos` 的 0.1 推出方向/符号不一致（:270 为 `+`、:408 为 `−`、:894 为 `−`、:776 与 :968 为 `−`）需统一。
13. **Circle-Map（§2.5）**：四方向采样（`pos±(r,0)`、`pos±(0,r)`，:434-438）必须换成球面采样（如 6 个轴向点或二十面体采样），或直接改为"球心到体素面/角的最近点"解析测试。
14. **Circle-Shape（§2.8）**：`Mat.Rotary({r,0})` / `Mat.Rotary({0,r})`（:568-569）是**共面两方向**，3D 需三个正交方向 + 球面采样；或改用"球心到网格三角形最近点"。
15. **Line 相关（§2.9-§2.12）**：`PhysicsLine` 的 `angle` 标量（:737、:842、:874、:919）→ 3D 方向；`Line->radius` 为半长；四阶段检测中的 `segmentIntersection` 全部要 3D 化；`MapOutline::face`（:943）的二维格边朝向 → 3D 体素面法线。
16. **接触点位置生成**：`contacts->position = normal * radius + center`（:487、:516、:544、:615）在 3D 仍是球面点，可直接推广；但 Shape/L 分支用 `info.pos`（体素命中点）需 3D DDA 给出面内命中点。
17. **接触点数上限与归约（§4）**：3D manifold 需引入"最多 4 点裁剪 + 按穿透深度排序"，并给所有 11 处无保护自增补 `ContactSize < PhysicsContactMaxSize`；`PhysicsContactMaxSize = 20` 对 3D 凸体接触偏大（3D 通常 4 点/对足够），需重新定值。
18. **`w_side` 语义重做**：3D 需 feature-id / 局部坐标哈希做跨帧冲量匹配，不能再用遍历序号（`PhysicsArbiter.cpp:10-100`）。

### 5.4 求解器（§3）
19. **双切向摩擦**：`Vec2_ tangent = Cross(c->normal, 1.0)` 的单切向（:88、:156、:260、:325、:433、:485、:581、:629）→ 构造正交基 `t1, t2`（`t1 = any ⟂ n`，`t2 = n × t1`）；`Contact` 需从 `FLOAT_ Pt` 扩为两个切向累积冲量（`Pt1/Pt2` 或 `Vec2_ Pt`）。
20. **摩擦锥**：`maxPt = c->friction * c->Pn`（:161、:330、:490、:634）与 `Clamp(Pt+dPt, -maxPt, maxPt)`（:165、:334、:494、:638）是 1D 区间夹紧；3D 必须改为在切平面圆盘内投影（若 `|Pt_vec| > μ·Pn` 则按比例缩放回半径）。
21. **有效质量公式**：`kNormal += I⁻¹(R − rn²)`（:84、:256、:429）是 2D 标量惯量形式；3D 为 `n · (I⁻¹ (r × n)) × r` 形式的张量项，`kTangent` 同理对 `t1`、`t2` 各算一次。
22. **力矩**：`Cross(c->r1, P)`（:103、:143、:173、:274、:313、:342、:444、:479、:500）与 `Cross(object->angleSpeed, c->r)`（:126-127、:152-153、:297、:322、:465、:482）从标量 → `Vec3_` 叉积；`angleSpeed` 更新从标量减法 → 向量 + 惯量张量作用。
23. **A 分支的切向符号不一致**：`PreStep` 用 `Cross(normal, 1.0)` 且 `P = Pn·n − Pt·t`（:433、:442），`ApplyImpulse` 却用 `Cross(normal, -1.0)` 且 `Pt = dPt·t`（:485、:498）。转 3D 时必须在 `t1`/`t2` 上重新统一符号约定，否则摩擦方向会随机反向。
24. **`r2 = {0,0}`**（:227、:247、:396、:420、:548、:572）→ `{0,0,0}`；`PreStep()` 无参版本（:47-56、:220-229、:389-398、:541-550）同样需 3D 化。
25. **注释与实现不符处**（转换时勿被误导）：`massNormal`/`massTangent` 注释称"有效质量的倒数"实为有效质量本身（`BaseArbiter.hpp:29-30`）；`ArbiterKey` 注释称"object1 <= object2"实为 `object1 >= object2`（`BaseArbiter.hpp:50`）；`ModulusLength` 返回平方但多处注释写成"距离"（`PhysicsBaseCollide.cpp:480`、:508、:535、:608）；§2.9/§2.11 的 `t = Dot(AP, AB) / len` 用长度平方作分母（:745、:885、:949）导致投影参数 `t` 量纲错误。
26. **序列化**：`JsonSerialization`（`BaseArbiter.hpp:153-167`）与 `JsonContrarySerialization`（:174-188）用 `SerializationVec2`/`ContrarySerializationVec2` 写 `position`、`normal`，3D 需换 `Vec3_` 序列化，并新增 `Pt` 第二分量。
